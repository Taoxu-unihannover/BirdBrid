# 真机策略评估

本章把 AI 策略真正跑在**真实机械臂**上：机器人自动执行"抓试管放入试管架"任务。你部署的服务（第 6 章的前端壳）在这一章被真正调用起来。

:::{dropdown} 动手前你需要准备什么？
- 从臂（follower）已校准，双相机已识别（wrist / front 别插反）
- 你的前端壳已在服务器上跑着（第 6 章），后端引擎由教师维护
- 工作区已布置：垫上放 1~3 支试管，试管架保持在参考位置，灯已打开
- 评估用的客户端脚本和环境已由教师准备好
:::

## 学习目标

在本章结束时，你将能够：

- 启动真实机器人的策略评估，让机器人自动执行任务
- 观察推理结果是否合理（首步动作对不对、能否抓取）
- **安全地**停止评估，并按正确顺序重启

## 我们跑的是什么策略？

就是第 6 章那个 GR00T 模型，checkpoint 由课程统一指定。它收到「相机画面 + 一句话指令」，输出 16 步关节动作，机器人一步步执行。

## 工作区准备（先做）

1. 在垫子上放 1~3 支试管，试管架保持在参考位置。
2. 确认两台相机都能清楚拍到工作区。
3. 打开灯，调到合适亮度。

## 启动评估

打开终端（或按教师配备的环境进入），运行评估脚本：

```bash
python3 so101_eval.py \
    --robot.type=so101_follower \
    --robot.port="$ROBOT_PORT" \
    --robot.id="$ROBOT_ID" \
    --robot.cameras="{
        wrist: {type: opencv, index_or_path: 0, width: 640, height: 480, fps: 30},
        front: {type: opencv, index_or_path: 2, width: 640, height: 480, fps: 30}
    }" \
    --policy_host=192.168.1.6 \
    --policy_port=5582 \
    --lang_instruction="Pick up the vial and place it in the yellow rack" \
    --rerun True
```

:::{note}
- `index_or_path` 换成你第 2 章记下的相机索引（wrist / front）。
- `--policy_host` 填你前端壳所在机器的 IP（通常是服务器 IP），`--policy_port` 填**你工位的前端壳端口**（第 6 章部署时用的那个，如 `5582`）。这里就是"调用你的服务"。
- `--rerun True` 打开可视化窗口，方便你观察关节动作和相机画面，确认相机映射是否正确。
:::

## 观察评估过程

评估开始后，机器人会**先缓慢抬起到初始姿态**，然后进入推理模式：每轮拿到 16 步动作并逐步执行。

观察要点：

1. **初始姿态**是否平稳到位（各关节接近预设姿态）。
2. **首步动作**是否合理——模型是否"理解"了当前位姿（首步动作应该和当前位姿相差很小），夹爪是否准备抓取。
3. 抓取、放置过程是否有碰撞或异常。

:::{tip}
本项目实测（SO-101 真机闭环）：`move_to_initial_pose` 各关节误差 < 3°，策略返回 16 步动作、首步与当前位姿差 < 2.5°、夹爪张开准备抓取，16 步动作落地执行无碰撞。你看到的应与之类似；若有明显不同，优先检查相机映射和校准。
:::

## 安全停止与重启

:::{warning}
**停止顺序很重要：先在机器人 client 终端按 Ctrl+C 停止机器人，再（必要时）停止服务。** 千万别反过来先停服务，让机器人"失联"着继续动。
:::

- **只停机器人、想再跑一次**：在 client 终端按 Ctrl+C，然后重新执行上面的 `so101_eval.py` 命令即可。此时服务端（前端壳 / 后端）保持运行，不用重启。
- **要换模型或完全重启**：
  1. 先在两个终端都 Ctrl+C 停掉当前命令
  2. 按需换模型路径（这块通常由教师操作）
  3. 重新启动服务端，再启动评估客户端

:::{note}
- 评估开始时，机器人会缓慢抬起到初始姿态再进入推理。停止时（Ctrl+C），它会缓慢回到"home"姿态。
- 多轮评估之间，尽量让策略服务保持运行，只在换模型时重启。
:::

## 关键要点

- 真实评估 = 评估脚本当 client，**调用你部署的前端壳**拿动作，驱动真机执行。
- 先看**初始姿态、首步动作、夹爪状态**是否合理，再关注抓取结果。
- 停止顺序：**先停机器人 client，再停服务**。
