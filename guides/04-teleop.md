# 主从遥操作

本章你用手握住主臂（leader），让从臂（follower）**实时跟着你动**。这是熟悉机器人、也是后面「采集示教数据」的基础。

:::{dropdown} 动手前你需要准备什么？
- 主臂、从臂都已[校准](03-calibration.md)完成
- 已设置好端口和 ID 变量
- 工作区附近没有障碍物，灯箱、道具摆放与校准/仿真时一致
:::

:::{note}
本章的 `lerobot-teleoperate` 命令在**客户端容器内**执行。先进入容器：`sudo docker exec -it so101-client bash`，并在容器里重新设置 `$ROBOT_PORT`、`$TELEOP_PORT` 等变量（见[第 2 章](02-setup.md)）。
:::

## 学习目标

在本章结束时，你将能够：

- 用主臂遥控从臂，完成主从跟随
- 在操作界面中正确配置并查看两台相机的画面
- 养成安全的操作习惯

## 安全注意事项（先读再动手）

:::{warning}
电机一旦使能，机械臂就会动。务必遵守：

1. **电机启用时，别把手伸进机器人可能夹到你的位置。**
2. 确认线缆布置合理，别让机械臂运动时被线缆钩住。
3. 随时准备按 **Ctrl+C** 停止，必要时直接拔电源线。
4. 移动过任何设备后，重新检查工作区摆放。
:::

## 启动遥操作

1. 建议先让主臂和从臂摆到**相近的姿态**——因为启动后，从臂会往主臂的姿态靠拢。

2. 在终端运行：

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=$ROBOT_PORT \
    --robot.id=$ROBOT_ID \
    --teleop.type=so101_leader \
    --teleop.port=$TELEOP_PORT \
    --teleop.id=$TELEOP_ID
```

3. **移动主臂**，观察从臂如何跟随。

4. **试试**抓起一支试管，把它放进试管架（先只靠你的肉眼和直觉）。

5. 在终端按 **Ctrl+C** 停止遥操作。

:::{tip}
如果从臂不动、或方向/幅度不对，多半是校准或端口 ID 不对，回到[第 3 章](03-calibration.md)检查。
:::

## 用相机画面来操作

刚才你靠肉眼遥控。但 AI 模型**只有两台相机**能看到的世界，所以采集示教数据时必须改用相机画面来操作——这也让你体会到这个任务对 AI 有多难。

每个工作区有两台相机：

- **wrist（腕部相机）**：装在夹爪旁，抓取后会被挡住。
- **front（外部相机）**：固定在外侧，全程能看到工作区。

:::{dropdown} 为什么需要两台相机？
机器人抓起试管后，腕部相机（wrist）会被自己的手挡住。外部相机（front）在整个过程中持续看到工作区，保证策略始终有可用的视觉输入。
:::

带相机启动遥操作（用第 2 章记下的相机索引）：

```bash
lerobot-teleoperate \
    --robot.type=so101_follower \
    --robot.port=$ROBOT_PORT \
    --robot.id=$ROBOT_ID \
    --teleop.type=so101_leader \
    --teleop.port=$TELEOP_PORT \
    --teleop.id=$TELEOP_ID \
    --display_data=true \
    --robot.cameras='{
      "wrist": {"type": "opencv", "index_or_path": 0, "width": 640, "height": 480, "fps": 30},
      "front": {"type": "opencv", "index_or_path": 2, "width": 640, "height": 480, "fps": 30}
    }'
```

:::{note}
把 `index_or_path` 后面的数字换成你在第 2 章记录的实际索引（`$CAMERA_WRIST` 和 `$CAMERA_FRONT` 的值）。
:::

`--display_data=true` 会打开一个查看窗口（Rerun）展示相机画面和关节数据，方便你**只看相机画面**来操作。

:::{important}
**在遥操作和采集数据时，只用两台相机的画面来看，不要用你自己的肉眼从上方偷看。** 策略只能"看到"相机里的东西，你的示范也必须和策略的感知一致，否则会引入策略学不到的信息。
:::

## 操作练习

1. 只看两台相机的画面，抓起一支试管并放入试管架。
2. 重复几次，体会一下：抓手挡住 wrist 画面后，仅靠 front 画面完成任务有多难。
3. 记录你成功/失败的次数和原因。

## 关于延迟（来自实测）

主从跟随的延迟，**主要不是网络或软件造成的**，而是舵机的机械响应（机械臂关节实际转到位需要时间）。所以软件环节再优化，只能改善一部分；机械响应是这条链路的固有开销。

## 关键要点

- 主臂遥控从臂，两臂姿态先对齐再启动。
- 采集示教数据时**只用相机画面操作**，别用肉眼偷看。
- 停止用 **Ctrl+C**；随时准备干预是最重要的安全措施。
